# RAG + Agent 三阶段管道 — 用户故事

## US-1: 更快更稳的 AI 回复

**作为** 高职英语教师  
**我想** 发完消息后快速得到 AI 回复，不要等它来回调工具  
**以便** 我能高效进行教学研讨，不浪费时间

**验收标准**：
- 发送消息后，AI 在 2 秒内开始回复（不含网络延迟）
- 不再出现 AI 反复调用 get_state/get_current_time 的延迟
- 状态、时间、静默信息自动注入，不需要 AI 手动查询

## US-2: 记忆更好的 AI 助手

**作为** 经常咨询教学的老师  
**我想** AI 能记住我之前聊过的内容（研究方向、班级情况、课程偏好）  
**以便** 不用每次重复介绍自己

**验收标准**：
- Phase 2 自动检索个人记忆并注入 prompt
- AI 回复中引用"根据你之前的信息……"并准确
- 关键词提取精准，不遗漏重要记忆

## US-3: 按需深度思考

**作为** 设计复杂教案的老师  
**我想** 当我深入讨论教学方案时，AI 自动切换到更强的模型  
**以便** 复杂问题得到更专业的分析，简单问题快速回复

**验收标准**：
- 投入度 ≥ 90 或 AI 判定需要深度分析时，自动切换 deepseek-v4-pro
- 前端可手动关闭深度思考（省钱）
- 切换过程对用户透明，无感知

## US-4: 前端可控制 AI 行为

**作为** 教师  
**我想** 根据自己的需求开关深度思考和联网搜索  
**以便** 控制 AI 的回复质量和成本

**验收标准**：
- 输入框旁有深度思考开关按钮（大脑图标）
- 点击切换，即时生效
- 联网搜索开关预留（待模型支持后启用）

## US-5: 代码决定信息类工具，AI 专注对话

**作为** 平台开发者  
**我想** 状态/时间/静默/计算/翻译等确定性工具由代码自动执行  
**以便** AI 不用在 function calling 来回中浪费 token 和时间

**验收标准**：
- get_state/get_current_time/get_silence_timing/calc/translate/set_tone 全部由代码层执行
- AI 不再看到这些工具定义，只看到注入的结果
- AI 保留记忆读写、投入度调整、成就授予等需要判断的工具

## US-6: 工具可扩展

**作为** 平台开发者  
**我想** 新增一个工具只需改 4 个位置（定义/分类/触发/统计）  
**以便** 快速迭代新功能

**验收标准**：
- 新增预处理工具：tools.py + tool_router.py + preprocessor.py 关键词匹配 + pipeline.py 统计
- 新增主模型工具：tools.py + tool_router.py（Phase 3 自动可用）
- 不改 service 层、不改 API 层、不改领域接口

## US-7: 全阶段静默感知

**作为** 偶尔几天不上线的老师  
**我想** AI 知道我离开多久、历史上最长沉默了多久  
**以便** 重新对话时 AI 能自然问候，不尴尬

**验收标准**：
- 每轮自动注入全阶段静默：当前静默 / 上次长静默 / 历史最长静默
- 短沉默（< 2h）→ AI 自然承接，长沉默（> 2h）→ AI 先问候
