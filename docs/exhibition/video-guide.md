# 宣讲视频录制指南

## OBS 设置

1. 来源 → 添加 "显示器采集" 或 "窗口采集"（选 Chrome）
2. 设置 → 输出 → 录像：
   - 格式：MP4
   - 编码器：H.264
   - 分辨率：1920×1080
   - 帧率：30
   - 码率：8000 Kbps
3. 设置 → 音频 → 禁用所有音频设备（你不需要声音）

## 录制步骤

准备：打开网站 http://8.138.124.111，全屏浏览器（F11）

### Segment 1 — 首页展示（00:00-00:08）
| 操作 | 画面 |
|------|------|
| 停在首页 | Hero 区域 + 功能卡片全景 |
| 鼠标悬停几个功能卡片 | 展示 hover 动效 |

### Segment 2 — 教研社区（00:08-00:16）
| 操作 | 画面 |
|------|------|
| 点击导航"教研社区" | 帖子列表加载 |
| 点一个分类 tab | 筛选动效 |
| 点进一篇帖子 | Markdown 渲染 + 评论区 |

### Segment 3 — 暗色模式（00:16-00:25）
| 操作 | 画面 |
|------|------|
| 点导航栏主题切换按钮 | 白天 → 暗色切换过程 |
| 不同页面切一下 | 展示暗色全局生效 |

### Segment 4 — 情感分析（00:25-00:37）
| 操作 | 画面 |
|------|------|
| 点导航"情感分析" | 进入页面 |
| 点一个快捷示例 | 自动填入 + 分析 |
| 滚到热力图区域 | 注意力权重颜色 |

### Segment 5 — 架构展示（00:37-00:49）
| 操作 | 画面 |
|------|------|
| 切到 VS Code 或截图 | 展示三层架构代码/图 |
| 展示 ApiResponse 文件 | VO/DO 分层 |

### Segment 6 — AI 聊天室（00:49-01:02）
| 操作 | 画面 |
|------|------|
| 点导航"AI 聊天室" | 三栏布局 |
| 新建会话 → 发一条消息 | 打字机逐字输出 |

### Segment 7 — 结尾（01:02-01:15）
| 操作 | 画面 |
|------|------|
| 回到首页 | Hero 全景 |
| 鼠标指向底部/QR 码区域 | 展示二维码 |
