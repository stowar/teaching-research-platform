# 设计语言

## 色彩体系

以靛蓝为品牌主色（Indigo），象征专业、学术与信任感。

| 层级 | 色值 | 用途 |
|------|------|------|
| brand-50 | #eef2ff | 当前页面高亮背景 |
| brand-200 | #c7d2fe | 暗色模式高亮文字 |
| brand-400 | #818cf8 | 暗色模式 Logo |
| brand-600 | #4f46e5 | 按钮、链接、图标主色 |
| brand-700 | #4338ca | Hover 加深 |
| brand-900 | #312e81 | Hero 渐变起点 |

语义色：绿（成功）、红（危险）、黄（警告）、蓝（信息），每色有 50/100/200/400/500/600/700 七个层级。

文字色：主文字 `#1e293b`、辅助文字 `#475569`、三级文字 `#6b7280`，对比度满足 WCAG AA。

## 暗色模式

通过 `[data-theme="dark"]` 选择器全局切换，所有颜色走 CSS 变量，无需单独维护暗色版代码。

关键策略：暗色下卡片底色用 `rgba(255,255,255,0.03)` 透明层叠而非纯黑色——保留背景的深邃感同时卡片有层次。导航栏用半透明玻璃拟态 `backdrop-filter: blur(12px)`，暗色下仍能透过页面色调。

## 字形层级

- 大标题（Hero）：56-68px，字重 900，letter-spacing 8-10px，渐变色填充
- 页面标题：text-2xl 至 text-3xl，字重 700-800
- 卡片标题：text-base 至 text-lg，字重 600-700
- 正文：text-sm，行高 1.6，字重 400
- 辅助说明：text-xs，颜色走 text-tertiary

## 间距与圆角

8px 基准栅格：space-1(4px) → space-4(16px) → space-8(32px) → space-12(48px)。

圆角：按钮 md(6px)、卡片 lg(8px)、Hero 区 xl(12px)、弹窗 2xl(16px)。

## 动效原则

- 进入：translateY(20px) → 0，0.4-0.6s，ease-out
- Hover：scale(1.02) 或 translateY(-1px)，0.15s
- 情感分析图标：浮动循环 3s ease-in-out
- 渐变背景：background-position 循环 8s，增加页面"呼吸感"
- 按压力反馈：scale(0.97)，0.1s

全部动画收敛到三个时长变量（fast/normal/slow）和一条缓动曲线（ease-out），不出现生硬的线性过渡。

## 设计决策

1. **玻璃拟态导航**：不挡内容，有层次，暗色下也有质感
2. **Emoji → SVG 图标**：全站 lucide 矢量图标，暗色自动变色
3. **Hero 统一视觉语言**：渐变+点阵+浮动图标，所有页面 Hero 区结构一致
4. **功能卡片前置**：首页和落地页都用卡片提前展示功能，减少用户探索成本
